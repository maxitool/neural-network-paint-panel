# NewPaintPanel — Десктопная панель рисования и локальный интерфейс ИИ 🖌️

**NewPaintPanel** — это клиентское графическое приложение на базе библиотеки `tkinter` (Python), предназначенное для локального тестирования каскадной системы сверточных нейронных сетей (CNN) по распознаванию рукописных японских иероглифов (кандзи) в реальном времени. Приложение предоставляет интерактивную холст-панель для рисования, осуществляет нативную нормализацию растра средствами C++ и выводит визуальную карточку распознанного символа из встроенной базы данных.

## 🛠️ Технический стек проекта

*   **Интерфейс (GUI):** `tkinter` — построение графического окна и обработка событий рисования на Canvas.
*   **Глубокое обучение:** TensorFlow 2.x / Keras — инференс локальных весов моделей и топология сетей.
*   **Обработка изображений и вычисления:** Pillow (PIL), NumPy — манипуляция матрицами, формирование картинок (`Image.png`) для тестирования нормализации и подготовка тензоров.
*   **Локальное хранилище данных:** SQLite3 (`kanji_information.db`) — индексация и сопоставление символов кандзи с их идентификаторами для вывода карточек.
*   **Системная интеграция:** Встроенная библиотека `ctypes` для вызова высокопроизводительных С-функций нормализации из динамических библиотек `.so`.

## 🧠 Архитектура каскадной системы классификаторов (CNN)

Для обеспечения высокой точности распознавания среди сотен схожих по начертанию иероглифов система использует **двухуровневую каскадную модель**:

1.  **Главный классификатор (`Weights/Main.h5`):** Принимает нормализованную матрицу и распределяет изображение по 54 базовым структурным группам. Порог отсечения для активации группы составляет \(p \ge 0.2\).
2.  **Второстепенные классификаторы (`Weights/{group_number}.h5`):** Если главная сеть определила группу (от 0 до 52), динамически подгружаются веса соответствующей узкой подсети для вычисления точного кандзи с порогом вероятности \(p \ge 0.55\).
3.  **Исключение (Группа 53):** Если главный классификатор относит рисунок к группе `53`, система автоматически идентифицирует простейший иероглиф «一» (одна черта), минуя инференс вторичных сетей, и сразу отображает финальный результат (`i512.png`).

### Топология сверточной сети (Keras Sequential)
Каждая нейросеть (как главная, так и 53 вторичных) имеет идентичную однородную структуру, оптимизированную под бинарные контурные изображения:

```python
model = keras.Sequential([
    Conv2D(32, (3,3), padding='same', activation='relu', input_shape=(64,64,1)),
    Conv2D(32, (3,3), padding='same', activation='relu'),
    MaxPooling2D((2,2), strides=2),
    Conv2D(64, (3,3), padding='same', activation='relu'),
    Conv2D(64, (3,3), padding='same', activation='relu'),
    MaxPooling2D((2,2), strides=2),
    Flatten(),
    Dense(512, activation='relu'),
    Dense(256, activation='relu'),
    Dense(countClasses, activation='softmax')
])
```

## ⚙️ Алгоритм работы и нативная интеграция C++

1.  **Сбор данных:** Пользователь рисует символ черным цветом на белом холсте размером 640x640. Приложение считывает состояние пикселей (`1.0` — черный, `0.0` — белый) и сохраняет матрицу во временный файл `data.txt`.
2.  **Нативная нормализация (`NormalizationEx3.so`):** Для оптимизации и ускорения расчетов (центрирование, масштабирование, приведение к размеру 64x64) файл обрабатывается скомпилированной C++ библиотекой через интерфейс `ctypes`. Результат пишется в бинарный файл `data.txt`.
3.  **Инференс и Вывод:** Скрипт считывает нормализованную матрицу, формирует проверочный снимок `Image.png`, пропускает тензор через каскад нейросетей, ищет полученный символ в БД `kanji_information.db` и выводит графическую карточку кандзи из папки `Images/`.

## 📂 Структура файлов проекта

Для успешной работы приложения директория должна сохранять следующую иерархию:

```filesystem
├── NewPaintPanel.sln         # Файл решения Visual Studio
├── README.md                 # Документация проекта
├── .gitignore                # Файл исключений Git
└── NewPaintPanel/            # Корневая папка приложения
    ├── NewPaintPanel.py      # Главный исполняемый скрипт (Tkinter + Инференс)
    ├── NewPaintPanel.pyproj  # Файл проекта Python
    ├── kanji_information.db  # База данных SQLite с индексами кандзи
    ├── ALL_CLASS_KANJI.txt   # Текстовая карта распределения символов по группам
    ├── data.txt              # Вывод изображение в виде матрицы цветов после нормализации
    ├── Image.png             # Сгенерированное нормализованное изображение 64x64
    ├── NormalizationEx3.so   # Активная C++ библиотека нормализации (используется по умолчанию)
    ├── NormalizationEx2.so   # Альтернативная сборка библиотеки нормализации
    │
    ├── Weights/              # Каталог весов обученных нейросетей
    │   ├── Main.h5           # Веса головной нейросети (классификатор групп)
    │   ├── 0.h5              # Веса подсети для группы 0
    │   └── ...               # Веса подсетей для остальных групп (до 52.h5)
    │
    ├── Images/               # Карточки иероглифов для вывода пользователю
    │   ├── i1.png
    │   ├── i2.png
    │   └── ...               # Набор карточек (включая служебные, например i512.png)
    │
    └── Normalization_versions/ # Архивные и экспериментальные версии C++ библиотек
        ├── NormalizationV1.so
        └── ...
```

1. Установите необходимые Python-зависимости (требуется Python 3.9+):
   ```bash
   pip install tensorflow numpy pillow colorutils
   ```

2. Запустите графическую панель:
   ```bash
   python NewPaintPanel/NewPaintPanel.py
   ```
